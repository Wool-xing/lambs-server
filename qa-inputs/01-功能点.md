# 功能点清单（反推: 需求文档 §2 + main.go 路由 + 记忆图谱, 2026-08-28）

## 2.1 数据源（7 类）
PG / MySQL / Mongo / Redis / SQLite / REST 约定式 / Qdrant 向量 — 连接测试、表浏览 CRUD、同步、备份、脱敏导出（CSV/用户表）、按源类型视图（表格/DocView/KVView/VectorView）
## 2.2 共享服务按需
注册表 {name,start_cmd,stop_cmd}、引用计数 0→1 启动 1→0 停止、上线顺序 共享→TCPProxy→专属、内存门控 LAMBS_MIN_FREE_MB
## 2.3 项目生命周期
创建/编辑/删除、状态机 online/offline/maintenance（同态 noop 守卫）、进程管理（启停/重启/状态/日志）、TCPProxy、HealthMonitor 30s 巡检自愈、计划任务 cron（双通道: agent/tailscale）
## 2.4 认证与权限
注册（开放）、登录（限流 5r/m + 盐哈希）、忘记密码（验证码 HMAC + sha256 + 账号级限频）、JWT + token_version 失效、RBAC 三角色、gate 停用拦截
## 2.5 备份
GPG 加密 → TG 频道上传、备份列表/恢复/下载、WAL 安全
## 2.6 前端体验
仪表盘统计卡（按源类型实时）、系统日志卡（journald）、项目详情（数据/成员/日志/进程）、TypeSelect 全站统一、12 主题、通知中心、审计日志分页、设置（配置/数据源掩码）
## 附加
多机监控（wool 节点）、tg-bot 通知通道、健康检查排除纯数据源项目、CSV 导入导出、RBAC 越权矩阵
